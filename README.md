# Ana Estrada · Fotografía Deportiva

Portafolio de fotografía deportiva: fútbol, basquetbol, carreras, lazo, voleibol y golf.

Sitio estático (HTML, CSS y JS sin dependencias). Para publicarlo en Vercel: importa este repositorio, elige "Other" como framework y deja vacíos el comando de build y el directorio de salida.

- `index.html`: la página
- `img/`: fotos optimizadas para web
- `fonts/`: tipografías incluidas en el sitio
- `CV_Ana_Estrada_Fotografia_Deportiva.pdf`: CV descargable
